# PetCare_OOP
Examen parcial de la EE de Diseño y Programación Orientada a Objetos. La clínica veterinaria PetCare necesita un sistema de consola para registrar a sus mascotas y dueños, agendar citas, registrar consultas y calcular lo que cobra por cada servicio. Tú eres el equipo de desarrollo: debes entender el problema, modelarlo y construirlo
